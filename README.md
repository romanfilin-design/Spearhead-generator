# Sand & Bone — Генератор сражений

Трекер для Warhammer Age of Sigmar: Spearhead — армии, карты твистов, тактики и очки победы для терейна Realm of Death. Чистый HTML/CSS/JS, без сборки и зависимостей.

Живая версия: **https://romanfilin-design.github.io/Spearhead-generator/**

## Структура

- `index.html` — само приложение
- `armies.json` — данные армий (боевые черты, способности, юниты, оружие, улучшения)
- `assets/textures/` — портреты юнитов

`index.html` подгружает `armies.json` через `fetch`, поэтому локально нужен веб-сервер (например `python3 -m http.server`) — просто открыть файл двойным кликом не сработает, браузер блокирует `fetch` для `file://`.

## Как добавить новую армию

Всё делается через чат с Claude, без API-ключей и без ручного редактирования JSON:

1. Прислать официальный PDF Spearhead-варскролла (на английском).
2. Claude читает его и формирует запись в `armies.json` в том же формате, что и существующие армии — названия юнитов/способностей на английском (как в оригинале), пояснения и эффекты — пересказ своими словами на русском.
3. Проверяешь результат в чате, просишь поправить при необходимости.
4. Коммит и пуш в этот репозиторий — GitHub Pages пересобирается автоматически.

## Как добавить портреты юнитов

Самый дешёвый вариант — заранее подобранные фото:

1. Положить фото каждой миниатюры (одна модель на фото, любой фон) в `source_portraits/<army_key>/<unit_key>.jpg`, имена — как ключи в `armies.json`.
2. Запустить `Warhammer/.venv-tools/process_army_portraits.py <army_key>` — скрипт сам уберёт фон, обрежет пустые поля, впишет пути в `armies.json` и соберёт контакт-лист для проверки.
3. Проверить контакт-лист, закоммитить и запушить.

Если готовых фото нет — можно прислать PDF варскролла, Claude вырежет портреты из него тем же способом, каким сделаны существующие.
