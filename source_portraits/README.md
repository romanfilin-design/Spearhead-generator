# Портреты юнитов — исходники

Самый дешёвый способ добавить портреты для новой армии.

## Как класть файлы

```
source_portraits/<army_key>/<unit_key>.jpg
```

`army_key` и `unit_key` — точно как в `armies.json` (например `kharadron_skyhammer/arkanaut_admiral.jpg`).
Формат не важен: jpg, jpeg, png, webp — все ок. Фон может быть любой, главное чтобы миниатюра была видна целиком и не перекрыта другими моделями/текстом — если на фото несколько миниатюр, кадрируй сам до одной перед тем как класть сюда.

## Обработка

```
Warhammer/.venv-tools/bin/python3 Warhammer/.venv-tools/process_army_portraits.py <army_key>
```

Скрипт сам: снимет фон (rembg), обрежет прозрачные поля, впишет путь в `armies.json`,
соберёт один контакт-лист `source_portraits/<army_key>/_contact_sheet.png` (до/после по каждому юниту)
для одной проверки одним взглядом вместо разбора по одному юниту.

Если PDF-варскролл — сначала вручную вырезать нужный кадр с миниатюрой (см. предыдущие армии как пример),
сохранить как `<unit_key>.png` в эту папку, дальше тот же скрипт.
